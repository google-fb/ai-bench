# llm-museum

多個 agent 針對同一份任務做出來的結果。原始任務在 [`prompt.txt`](prompt.txt)：用 Three.js 做一座 3D 博物館，拆解三個最有名的大語言模型架構（例如 DeepSeek V4.1 Flash），支援中英文切換與可調速的瀏覽器語音朗讀，風格為好閱讀的大地色系。

參考截圖是別人用 Astra 讀 DeepSeek V4.1 Flash 論文後，把它與原始 Transformer 並排做成 3D 架構圖的概念。
