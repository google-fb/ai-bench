# AI Benchmark Wiki

繁體中文 AI 基準測試百科，以高中生也能理解的語言，介紹 [Artificial Analysis Evaluations](https://artificialanalysis.ai/evaluations) 網站上的各項 AI benchmark。

## 內容涵蓋

- **28 項 benchmark** 的完整介紹（繁體中文）
- **基礎概念**：什麼是 benchmark、測試集、分數意義、評分方法
- **八大分類**：綜合指數、知識推理、數學、程式設計、AI 代理、專業應用、多模態、專項測試
- 每項測試包含：測試說明、測試集內容、測試流程、分數解讀、評分方法

## 本地執行

```bash
npm install
npm run dev
```

開啟瀏覽器前往 [http://localhost:4317](http://localhost:4317)

## 建置

```bash
npm run build
npm start
```

## 技術棧

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- shadcn/ui
