# artificialanalysis

這個資料夾用來放多個 agent 針對同一份任務（重製 [Artificial Analysis](https://artificialanalysis.ai/) 風格網頁）做出來的結果。

之後解壓縮進來的每個 zip 會變成這裡的一個子資料夾，例如：

```text
artificialanalysis/
  agent-a/
  agent-b/
```

對應網址：

```text
https://google-fb.github.io/ai-bench/artificialanalysis/agent-a/
https://google-fb.github.io/ai-bench/artificialanalysis/agent-b/
```

索引頁：<https://google-fb.github.io/ai-bench/artificialanalysis/>
